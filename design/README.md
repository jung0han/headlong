# design/

Design documents. Some describe the current system, e.g.
[trajectory_spec.md](trajectory_spec.md) and
[THINKERS_spec.md](THINKERS_spec.md). Others are proposals and
explorations kept as a record of how the design got here, e.g.
[headlong.md](headlong.md) and
[porting-shelly-to-be-headlong-like.md](porting-shelly-to-be-headlong-like.md).
When a document and the code disagree, the code wins.

The accepted design for the personal assistant prototype is in
[personal_assistant_prototype.md](personal_assistant_prototype.md).

Reference documentation for users belongs in [docs/](../docs/).
