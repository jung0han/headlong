# Issue tracker: Linear

Work Items and specifications for this repository live in Linear.

- Workspace: `Development`
- Team: `정동우`
- Project: `HeadLong`
- Canonical Work Item identity: the Linear issue identifier

Use the connected Linear tools to create, read, update, relate, and close Work
Items. Preserve native `blocked by` and `blocks` relations when splitting work.

GitHub remains the source-code, pull-request, and upstream collaboration
surface. GitHub Issues are not the canonical tracker for this fork.

When a skill says “publish to the issue tracker,” create or update a Linear
issue in the `HeadLong` project.

When a skill says “fetch the relevant ticket,” retrieve the Linear issue by its
identifier, including relations and comments.
