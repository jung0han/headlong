# Separate personal memory from activity and references

HeadLong's append-only trajectory is the Canonical Authority for observations,
user authorization, promotion, rejection, and supersession events, while Active
Memory is a rebuildable current-state projection. Saved web content belongs to
the separate Reference Store, and user-authored long-form knowledge remains in
the Personal Wiki. Reading or saving a Reference or Wiki page never promotes it
to Active Memory without the authority required by ADR 0001.
