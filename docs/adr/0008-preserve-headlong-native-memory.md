# Preserve HeadLong's native memory behavior

The Observer retains HeadLong's existing Markdown memory store, `mem`
commands, memory screen, and native thinker's ability to add reusable lessons.
Active Memory remains ledger-backed but is projected into the native store in
HeadLong-compatible form. Memory Candidates may use a separate review surface
but are not a required promotion gate. This preserves mature HeadLong behavior
while retaining evidence and history as additional assistant capabilities.
